# WATTERRA — Public Project Repository

This repository contains reviewed, public-facing information about WATTERRA.

## Project scope

WATTERRA is an early-stage technical research project exploring software for organizing energy-project information, evidence, verification records, and associated rights data.

## What this repository is

- A public project-information website.
- Selected public documentation and educational technical material.
- A transparent summary of development status and limitations.

## What this repository is not

- It is not evidence of a production energy registry or live energy integration.
- It does not establish ownership of electricity, renewable-energy certificates, or other real-world assets.
- It does not offer tokens, investments, financial services, or guaranteed returns.
- WTR is not represented here as deployed, exchange-listed, or redeemable for electricity.

## Development status

The public website is an informational prototype. Technical components must be independently reviewed and tested before any operational use. No production deployment is claimed.

## Repository separation

The private repository remains the source for internal project material. Only content specifically reviewed for public release belongs here. Never publish credentials, private keys, seed phrases, personal data, internal commercial information, or unreviewed documents.
