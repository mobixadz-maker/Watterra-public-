# WATTERRA public website

This directory contains the reviewed static project-information website.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this public repository.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. The workflow at `.github/workflows/deploy-website.yml` deploys the contents of this directory when website files change on `main`.
4. Check the **Actions** tab for the workflow result. GitHub Pages will show the site URL in **Settings → Pages** after a successful deployment.

## Publication rules

- Keep internal specifications, private project records and confidential material in the private repository.
- Publish only reviewed public-facing content here.
- Never commit credentials, private keys, seed phrases, personal data or secrets.
- The site is informational. It does not sell tokens, provide investment services, or claim WTR is deployed or redeemable for electricity.
